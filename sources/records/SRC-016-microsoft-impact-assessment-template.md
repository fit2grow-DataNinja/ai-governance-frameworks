- Publisher: Microsoft

## Relevance

- Claim or topic being investigated: Whether the published template contains reusable prompts and records that can be classified by intent and mapped to AI RMF outcomes.
- Exact provision, framework section, or example: Sections on system information, lifecycle, purpose, geography, deployment mode, intended uses, stakeholder benefits/harms, data requirements, and impact summary.
- Why it is relevant to this repository or project: It is a concrete working form, not merely a high-level principles statement, and provides a useful comparison for the repository’s assessment-record design.

## What the source says

The template collects system/team information and reviewers; lifecycle stage and planned releases; system purpose, features, geography, deployment mode, and intended uses; stakeholders and potential benefits/harms; fairness considerations; data requirements and existing-data suitability; and an impact summary. It includes goal-applicability questions and asks the user to explain why a goal is marked not applicable.

## Evidence and limits

- Actions, controls, or evidence described by the source: A structured form intended to support Microsoft’s impact assessment process and publicly shared as a reusable template.
- What the source does not establish: A blank template does not show that an assessment was completed, decisions were approved, controls were implemented, or harms were mitigated.
- Scope, assumptions, or limitations: Microsoft states the template was edited for external release, including removal of internal links, references, and examples. It is dated 2022; currentness and suitability for a new context require review.
- Does the source state whether the example is validated, endorsed, or illustrative? Microsoft describes it as an externally released template; it is not independently validated by this review.

## Our analysis

- Possible relevance to a project or reusable document: Direct thematic mapping to MAP 1.1 (context, purpose, settings), MAP 2.1 (tasks and methods, where captured), MAP 3.3 (application scope), MAP 5.1 (stakeholder benefits/harms), and partial mapping to MAP 2.3 (data requirements/suitability).
- Adaptations required and rationale: Treat its questions as examples of assessment prompts, not NIST requirements. In the crosswalk, cite the exact section and distinguish template structure from completed evidence.
- Open questions: The linked impact-assessment guide may explain how Microsoft expects users to answer and review some fields; it was outside this bounded first pass.
- Confidence: High that the template contains the described fields; no conclusion about completed use.
